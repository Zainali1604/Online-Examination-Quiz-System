About the Project

The Online Examination & Quiz System is a college-level Web Application designed using Django, Bootstrap 5, PostgreSQL, and Chart.js.

Key Features

  • Role-based access control (Admin, Teachers, Students).
  • MCQ Exam creation with options, correct answer selection, duration, and publishing lifecycle.
  • JavaScript live countdown timer with automatic server-side validation.
  • Instant evaluation, score reports, percentage calculations, and answer review.
  • Dashboard analytics powered by Chart.js.
